## 🤔 什么是 Gemini Omni？

**Gemini Omni** 是 **Google** 开发的视频生成模型，支持通过图片、视频、音频和文本等多模态输入生成视频。

**Key Features:**
- 🎥 **文本生成视频** — 根据文字描述生成视频
- 🖼️ **图片生成视频** — 将静态图片动画化为动态视频
- 📹 **视频转视频** — 转换和扩展现有视频
- 🎵 **音频驱动** — 通过音频输入驱动视频生成
- 📐 **最高 1080p 分辨率**，4-15 秒时长
- 🔊 **自动配音配乐** — 自动旁白和背景音乐

### X 财报庆祝动态图形

![日本語](https://img.shields.io/badge/lang-日本語-green)

> 一个为 Gemini Omni 设计的高细节动态图形提示词，用于制作 X 财报里程碑的庆祝动画，包含复杂的 3D 旋转、粒子特效和同步排版。

#### 📝 提示词

```
请仅使用随附图片作为唯一参考图。始终使用同一张图片；仅对位置、缩放、旋转、3D 旋转和复制进行动画处理。请勿生成或重绘新的插图。制作高质量的动态图形。视频效果应达到 After Effects 制作的商业级水准。整体氛围为“成功”、“翻倍”、“庆祝”和“喜悦”。背景明亮华丽，金色光芒、五彩纸屑、闪光、粒子和庆祝特效优美地舞动。整个视频传递出积极向上的氛围。

视频开始时，随附图片出现在屏幕中央。图片强劲地放大，并有节奏地重复“放大 -> 缩小 -> 放大”的过程。伴随着弹跳动画，金色光芒和闪光向四周扩散。

接下来，图片绕中心快速旋转 360 度，平滑过渡到沿 Y 轴的 3D 旋转（卡片翻转）。摄像机也进行轻微的前后移动以营造深度感。金色丝带状的光芒和粒子随着旋转同步盘旋，强调节日氛围。

在 3D 旋转结束的瞬间，图片立即从一张分裂为四张。这四张图片飞向屏幕四角，每一张都继续旋转、缩放并留下优美的光迹。

紧接着，四张图片进一步分裂为 16 张，均匀分布在屏幕上。这 16 张图片以不同的时机重复旋转、3D 旋转和缩放，不断增殖以填满屏幕。背景中，五彩纸屑、金色粒子、星形光芒和庆祝特效宏大地舞动，在视觉上强调“翻倍”的意象。

最后，所有 16 张图片高速向中心汇聚，瞬间融合成一张。当摄像机急剧推向融合后的图片时，金色光芒爆发，五彩纸屑填满屏幕。视频以庆祝成功的极其华丽的结尾收场。

确保视频全程无静止时刻，保持明快且充满活力的节奏。动作应平滑而锐利，目标是达到广告、商业片或音乐录影带级别的高质量动态图形。

排版呈现（庆祝/翻倍版本）

排版应与图片的动作完美同步。文字置于图片前方，使用粗体、现代且奢华的无衬线字体。为字符添加金色光泽、发光效果、光晕和动态模糊，以营造庆祝且高端的视觉效果。

0–2 秒：巨大的“X”强劲地缩放进入，与图片的缩放同步跳动。金色光芒和闪光向四周扩散。

2–4 秒：配合图片的 3D 旋转，“Earnings”一词从背景中跳出，大胆放大。伴随着金色光迹，呈现出象征成功和利润的特效。

4–6 秒：“Doubled”一词强有力地跳入屏幕中央，显著放大。经过轻微弹跳后，金色光芒在屏幕上扩散，强调“收益翻倍”的影响力。

6–8 秒：当图片分裂为 4 张和 16 张时，多个“X”符号出现并有节奏地在屏幕上增殖。五彩纸屑、金色粒子和星形光芒在背景中舞动，将庆祝气氛推向高潮。

8–10 秒：所有图片和文字汇聚在中心，“X”、“Earnings”和“Doubled”重叠形成一个强有力的标题。随着摄像机推近，金色光芒爆发，五彩纸屑倾泻而出。视频以奢华而清爽的结尾结束，庆祝“收益翻倍！”。
```
